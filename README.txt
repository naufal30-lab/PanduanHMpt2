BTN FARM COMPANION — PWA ANDROID

Isi:
- index.html: aplikasi utama
- manifest.webmanifest: identitas PWA
- sw.js: cache offline
- icon.svg: ikon aplikasi

CARA MEMASANG DI ANDROID:
1. Unggah semua file (bukan folder ZIP) ke repository GitHub.
2. Aktifkan GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root) > Save.
3. Tunggu URL GitHub Pages aktif.
4. Buka URL tersebut melalui Google Chrome Android.
5. Menu ⋮ > Install app / Tambahkan ke layar utama.

FITUR:
- Checklist harian 3 tahun; tanggal, musim, tahun, catatan.
- Kalender 360 hari dengan festival dan sebagian ulang tahun yang tercantum di panduan.
- Referensi tanaman, harga benih, harga jual, waktu tumbuh, pola panen.
- Ringkasan festival, beberapa penduduk dan hadiah.
- Referensi alat, harga ternak, perluasan, lokasi, dan 11 Power Berry.
- Catatan saldo/target, checklist kemajuan 3 tahun.
- Simpan lokal, ekspor/impor backup JSON, cache offline.

CATATAN SUMBER:
Konten permainan diringkas dari “Panduan Harvest Moon: Back To Nature Bahasa Indonesia” oleh Swandriya, Jakarta–Indonesia, versi 1.0 Januari 2014. Pengarang meminta nama asli tetap dicantumkan dan karya turunan tetap gratis. Aplikasi ini gratis dan fan-made, tidak resmi/berafiliasi dengan pemilik game.
Tidak semua detail 91 halaman dimasukkan ke versi ini. Checklist harian adalah checklist pengelolaan umum yang bisa dicentang sendiri, bukan walkthrough harian yang diklaim berasal dari PDF. Data kalender dan tanaman mengikuti bagian panduan yang tersedia; periksa juga kalender di dalam game.
Data progres disimpan di browser perangkat. Hapus data browser dapat menghapus progres; lakukan ekspor backup secara berkala.
